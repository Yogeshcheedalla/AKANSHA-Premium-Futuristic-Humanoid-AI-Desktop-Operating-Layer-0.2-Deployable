What Akansha Does

Everything, Coherently.

Intelligence proportional to the task. A greeting costs zero model calls; a complex mission orchestrates parallel agents.

Multi-Provider Intelligence

Ollama, Gemini, OpenAI, any OpenAI-compatible Base URL, llama.cpp and local servers — all behind one router. Add a provider, test it live, set fallback priority. Switch without touching architecture.

Tiered Thinking

Five intelligence tiers. “What time is it?” resolves in ~14 ms with zero tokens. “Build this app” escalates to parallel agents with a real token and time budget. Never over-engineering a simple request.

tier0-deterministictier1-chattier4-parallel-agents

Evidence-Based Verification

A tool returning is not success. Akansha observes the resulting state and compares it to the expected state before reporting completion. If verification fails, it says so honestly.

observeverifyno-evidence-no-success

Memory That Forgets

Every candidate memory is scored on importance, future usefulness, recurrence and sensitivity. Noise is discarded, sensitive material is deprioritised, only high-value knowledge persists. Accurate recall, low cost.

workingepisodicsemanticproceduralscoring

Automatic Escalation

When DOM automation fails on a canvas or CAPTCHA, Akansha classifies the cause and climbs an eight-rung ladder — accessibility tree, browser automation, vision, computer use, Windows UIA, then user confirmation.

page-agentbrowser-useui-tarswindows-uia

Cross-Mission Learning

Capabilities that fail lose score; capabilities that succeed gain it. If Page Agent repeatedly fails on a site, the router learns to prefer vision there. Experience-driven routing, persisted across sessions.

lessonscapability-scoresexperience-routing

Vault-Secured Credentials

API keys are encrypted at rest and referenced by opaque ID. Never in the frontend bundle, never in logs, never in traces, never in mission history, never sent to a model prompt.

aes-256-gcmcredential-vaultzero-leak

Idempotent Execution

Every request carries a requestId. Duplicates — whether from HTTP, WebSocket or repeated ASR finals — replay the stored result instead of executing twice. One utterance, one mission, one response, one speech.
